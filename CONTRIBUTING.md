# Contributing to LogHawk

Thank you for your interest in contributing to LogHawk.

LogHawk is source-available software licensed under the PolyForm Perimeter License 1.0.1.

Before contributing, please read:

*   `LICENSE`
*   `NOTICE`
*   `ContributorLicenseAgreement.md`

## 1\. Contribution Model

Contributions to LogHawk are welcome.

Contributions may include:

*   Bug fixes
*   Security improvements
*   Performance improvements
*   Log ingestion and parsing
*   Anomaly detection
*   Machine learning
*   AI/LLM integrations
*   RAG functionality
*   Database integrations
*   Observability integrations
*   AWS integrations
*   Ollama/local-LLM integrations
*   Documentation
*   Tests
*   Infrastructure and deployment improvements
*   Developer tooling

For substantial architectural changes, please open an issue before starting implementation so the proposed change can be discussed with the maintainers.

## 2\. Contributor License Agreement

Before a contribution is accepted, the contributor must agree to the LogHawk Contributor License Agreement (`CLA.md`).

The CLA is intended to establish that:

1.  The contributor has the right to submit the contribution.
2.  The contributor retains ownership of the copyright in the contribution unless separately assigned.
3.  The LogHawk project receives the rights necessary to use, modify, distribute, maintain, and commercially develop the contribution.
4.  The project can continue to develop and distribute LogHawk if its commercial or licensing structure changes in the future.

## 3\. Copyright

Unless separately assigned in writing, contributors retain copyright in their original contributions.

Acceptance of a contribution does not by itself transfer copyright ownership to the LogHawk maintainer.

The contributor grants the rights specified in `CLA.md`.

## 4\. Third-Party Code

Do not submit third-party code unless you have the legal right to submit it.

If a contribution contains third-party material, disclose:

*   The source
*   The copyright holder
*   The applicable license
*   Any applicable attribution requirements
*   Any restrictions that may affect LogHawk

Do not copy proprietary, confidential, employer-owned, or otherwise restricted code into LogHawk.

## 5\. Employer-Owned Work

If you are contributing as an employee, contractor, consultant, or representative of an organization, make sure that you have obtained all required authorization before contributing.

Do not submit code that belongs to your employer or client unless you have authorization to contribute it.

## 6\. Security and Confidential Information

Never submit:

*   Passwords
*   API keys
*   Cloud credentials
*   Access tokens
*   Private certificates
*   Personal confidential information
*   Proprietary customer data
*   Internal company source code

Security vulnerabilities should not be disclosed publicly before the maintainer has had an opportunity to address them.

## 7\. Pull Requests

Pull requests should include:

*   A clear description of the change
*   The reason for the change
*   Relevant tests
*   Test results where appropriate
*   Documentation updates where necessary
*   Third-party attribution information where applicable

Keep pull requests focused on a specific change whenever possible.

## 8\. Licensing of Accepted Contributions

Accepted contributions will be incorporated into LogHawk and distributed under the project's applicable licensing terms.

The contributor grants the project the additional rights specified in `CLA.md`, including rights necessary for future commercial development and licensing of LogHawk.

LogHawk is licensed under the PolyForm Perimeter License 1.0.1.

PolyForm Perimeter permits use, modification, and distribution subject to its license terms, including its restriction on products and services that compete with the software.

You should read the complete `LICENSE` before using, modifying, distributing, or contributing to LogHawk.

## 10\. Acceptance of Contributions

The maintainer may:

*   Accept a contribution
*   Request modifications
*   Reject a contribution
*   Remove a contribution
*   Request additional copyright or licensing information

Acceptance of a pull request does not alter the copyright ownership of the contributor unless a separate written assignment exists.

## 11\. Future Project Ownership

The LogHawk project may in the future be operated by a company, organization, foundation, or other legal entity.

The rights granted under `CLA.md` are intended to permit the continued development and distribution of contributions if the project is transferred to such an entity.

## 12\. Questions

If you have questions about contributing or licensing, please open an issue in the repository or contact the project maintainer.
